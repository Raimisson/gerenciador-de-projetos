# Critérios de inclusão e exclusão

| Código | Tipo | Critério operacional | Exemplo de aplicação |
|---|---|---|---|
| IN-POP | Inclusão | População/unidade: | |
| IN-INT | Inclusão | Intervenção/exposição: | |
| IN-OUT | Inclusão | Desfecho mensurado: | |
| IN-DES | Inclusão | Desenho: | |
| IN-PER | Inclusão | Período de publicação/dados: | |
| IN-LANG | Inclusão | Idiomas: | |
| EX-POP | Exclusão | População fora do escopo | |
| EX-INT | Exclusão | Intervenção diferente | |
| EX-OUTCOME | Exclusão | Desfecho não mensurado / só qualitativo | |
| EX-DESIGN | Exclusão | Desenho inelegível (ex.: opinião, editorial) | |
| EX-DUP | Exclusão | Duplicata / versão superada | |
| NO-FULLTEXT | Situação | Texto completo não obtido (registrar, não excluir silenciosamente) | |

Regras: cada exclusão em texto completo recebe **um** código principal; decisões do Claude
são registradas como `claude-proposal` e confirmadas por revisor humano em revisões sistemáticas.
